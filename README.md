# Nomad GroceryApp

Shop control center for inventory, orders, customers, and procurement.

**Live demo:** [nomad-grocery.vercel.app](https://nomad-grocery.vercel.app)

## Features

- Dashboard with Inventory, Orders, Customers, and Procurement
- Product inventory — add, edit, and track slots / remaining capacity
- Shared seller and buyer catalogs (`share=catalog`)
- Order creation and order detail flow
- Customer list, detail, and shared customer history
- Procurement list
- Packs / billing process (starter, add-on, trial)
- Explore Demo Mode and live mode after login
- Sheet sync and master cache for live data

## Tech Stack

- React 18
- Create React App
- lucide-react
- TypeScript tooling

## Getting Started

```bash
git clone https://github.com/Aritra59/nomad_grocery.git
cd nomad_grocery
npm install
npm start
```

Requires Node.js 18+ and npm 9+.

## Scripts

| Command | Description |
| --- | --- |
| `npm start` | Run development server |
| `npm run build` | Production build |
| `npm test` | Run tests |
